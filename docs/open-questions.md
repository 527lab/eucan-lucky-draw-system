# 待確認問題（open-questions.md）

> 每題都附上**預設做法**。在沒有答案之前，實作都依預設進行，而且全部都可以用設定值調整，不會卡住開發。
> 標記：🔴 開發或上線前必須確認　🟡 活動前確認即可　🟢 有空再決定

## A. 活動規則

| # | 問題 | 預設做法 | 對應設定 |
|---|---|---|---|
| A1 🟡 | 抽獎券規則：每個景點一張、集滿全部景點才有資格，還是完成 N 個景點就有資格？ | `per_spot`，每個景點一張 | `ticket.mode`、`ticket.minSpots`、`ticket.ticketsWhenComplete` |
| A2 🟡 | 照片要不要人工審核？由誰審？什麼時候審（當天即時還是晚上統一審）？ | `auto` 自動通過，管理員可以事後退件 | `review.mode` |
| A3 🟡 | 景點有幾個？名稱、順序、開放時段？每個景點都是必去的嗎？ | 由管理員在後台建立 | `spots` 表 |
| A4 🟡 | 「合照」的定義：照片中一定要有本人嗎？一張團體照能不能讓照片中的每個人都算？ | 每人自己上傳才算，系統不檢查照片內容 | — |
| A5 🟢 | 需不需要驗證「人真的在景點」？例如要求同時傳送 LINE 位置訊息 | 不驗證（信任制加上人工審核作為選項） | 未來可以加入 `spot.latitude/longitude` 和 `radius` |
| A6 🟡 | 上傳的開始和截止時間？最後一個景點離抽獎時間多近？ | 不限制開始時間，截止時間由管理員設定 | `upload.startAt`、`upload.deadlineAt` |
